1. Planeamento & Proposta

A GHS é uma solução integrada para resolver a morosidade e erro humano na gestão académica de Bissau. O foco principal é a digitalização segura e eficiente de matrículas e pagamentos.

Mão de obra do Desenvolvedor 3.000.000 XOF
Hospedagem VPS (Mensal) 12.000 XOF
Domínio (Anual) 8.000 XOF

2. Engenharia de Requisitos

Requisitos Funcionais

  • RF01: Autenticação multinível (Admin, Professor, Aluno).
  • RF02: Fluxo de aprovação de matrícula "Zero-Trust".
  • RF03: Geração automática de recibos em PDF.

Regras de Negócio

O acesso ao portal do aluno é estritamente condicionado à aprovação financeira e administrativa da matrícula, garantindo controlo total sobre a base de utilizadores ativos.

3. Arquitetura & CSS

Design de Interface

A interface foi concebida sob o dogma do Mobile-First. Utilizamos Vanilla CSS para garantir que o sistema carregue instantaneamente mesmo em conexões de baixa largura de banda (2G/3G).

Pilha Tecnológica: PHP 8.1, MySQL (MariaDB), Vanilla JS e CSS3 Grid/Flexbox.

4. Análise Crítica

Pontos Fortes: Extrema leveza e segurança de dados.

Melhorias Recomendadas: Implementação de API REST para aplicações nativas e sistema de notificações via SMS para alerta de propinas.
